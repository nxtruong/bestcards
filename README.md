# Pocket Perks — hosting folder

This folder contains the complete static app. Upload its contents to your HTTPS web host, preserving src/, config/, and docs/. No build or package installation is required.

1. Open index.html through your web URL, not file://.
2. Try sample stores and enter a purchase amount to check the demonstration.
3. Set the fixed people and config URL template in config/app.json.
4. Replace the fictional card rates and offers in config/profiles/ with real terms.
5. Set sample to false after reviewing all data.
