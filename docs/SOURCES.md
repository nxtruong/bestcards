# Data and platform references

Live merchant data comes from OpenStreetMap contributors and is queried using Overpass. Application code is MIT licensed; OpenStreetMap data is governed separately by ODbL and attribution requirements.

- OpenStreetMap copyright and license: https://www.openstreetmap.org/copyright
- Overpass API and public instance policies: https://wiki.openstreetmap.org/wiki/Overpass_API
- Overpass query language guide: https://wiki.openstreetmap.org/wiki/Overpass_API/Language_Guide
- OSM brand tags: https://wiki.openstreetmap.org/wiki/Key:brand
- Browser Geolocation API, secure context, and permission requirements: https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API
- Browser cross-origin resource sharing: https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS
- Chase category examples and exclusions: https://www.chase.com/personal/credit-cards/rewards-category-faq

The sample card rates and offers are fictional software examples. No issuer supplied or verified them. Check each actual offer's current terms yourself. A bank's merchant classification may differ from OSM's business category.

The app does not include map tiles, Google Maps, Apple Maps, issuer SDKs, or a merchant MCC database. It displays a business list rather than loading a map.
